### GitHub Pages

1. Push this repo to GitHub.
2. **Settings → Pages → Build and deployment**: Source **Deploy from a branch**, branch **main** (or **master**), folder **/ (root)**.
3. After the workflow runs, the site is available at:
   - **`https://<your-username>.github.io/Aristo-eng/`** for a project repo named `Aristo-eng`.

To use the root domain **`https://<your-username>.github.io`** (no path), create a repository named **`<your-username>.github.io`**, copy these files into it, and enable Pages on that repo’s **main** branch, **/ (root)**.
